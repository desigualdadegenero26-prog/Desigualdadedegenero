# Equity Pulse

crie um site informativo com a finalidade  apresentar ao público  informações sobre a diferença salarial entre mulheres e homem. O site deve ter dois gráficos, os graficos devem ter uma pesquisa salarial de homens, idade,  região. Também deve fazer outro gráfico com os mesmo dados para mulheres. Nesse site, crie um local para qualquer empresa realizar a pesquisa. Crie um botão, quando clicar, aparecer um  modal de login, assim que entrar no login, deve aparecer uma tela de cadastro da empresa , quando finalizado o cadastro,  vai criar um questionário, os dados da pesquisa, os dados da empresa devem ser utilizado com todas os dados de todas as empresa nos primeiros gráficos de apresentação do site, e  crie também a parte do site da empresa quando entra no login, deve aparecer  a pagina da empresa com os dados só da empresa,  e só a empresa cadastrada pode ver seus dados  vai ser aglomerado no primeiro gráficos. utilize a imagem das cores anexas como referência de cores da plataforma, o azul, para bordas e letras  o cinza para fundos e o dourados para contornos e botões,   na questão de cores utilizer só as cores da imagem anexa
